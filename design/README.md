# 설계 문서

앱에 아직 안 들어간 설계다. 아티팩트(claude.ai 에 올라간 페이지)로 만든 것이라
저장소 밖에 있으면 다음 세션이 못 찾는다 — 그래서 여기 같이 둔다.

## 여는 화면 · 오늘의 한 장

`opening-screen.html` — 브라우저로 열면 그대로 돌아간다.
왼쪽에서 「얼마 만에 왔나」를 바꾸면 카드가 어떻게 갈리는지 보인다.

원본 아티팩트: https://claude.ai/code/artifact/1e48a57b-f88a-4647-95e3-70bdf02b6502

### 무엇인가

앱을 열 때 나오는 화면이다. **머리(NS · NEXT SWING · 슬로건)는 고정이고,
가운데 「오늘의 한 장」만 매번 바뀐다.** 브랜드가 움직이면 매번 「보여주는 것」이
되고, 매일 보면 그게 제일 지겹다.

- 슬로건은 요일마다 갈아 끼운다 (`WEEKSLO` — 월 「당신의 골프를 관리해드립니다」 …
  일 「천천히 가도 괜찮습니다」)
- 가운데 한 장은 0.4초 뒤에 들어온다
- 여는 방법 세 가지를 견줄 수 있다 — 한 화면 / 두 단 / 홈 맨 위

### 카드 스물둘 · 갈래 아홉

| 갈래 | 카드 | 언제 |
|---|---|---|
| `comeback` | 돌아온 사람에게 | 오래 안 왔을 때 |
| `coach` | 한마디 도착 · 지금 보고 있어요 · 프로가 최근 남긴 말 … | 프로 쪽에 일이 있을 때 |
| `goal` | 남은 레슨 · 첫 스윙 올리기 | 할 일이 남았을 때 |
| `streak` | 연속 연습 · 연속 올린 주 | 3일 / 3주 이상 |
| `practice` | 이번 달 올린 영상 · 연습한 날 | 3개 / 5일 이상 |
| `with` | 함께한 지 · 몇 개월째 | 가입 30일 / 60일 이상 |
| `milestone` | 첫 스윙을 올린 날 | 첫 영상 · 2주 이내 |
| `rank` | 상위 몇 % | 상위 30% 안일 때만 |
| `cheer` | 오늘도 한 스윙 더 · 꾸준함에서 옵니다 · 오늘 하나 어때요 | 언제나 (기본값) |

### 뽑는 규칙

**「얼마 만에 왔나」가 갈래 순서를 정한다.** 같은 사람도 사흘 만과 스무 날 만은
다른 말을 들어야 한다.

| 문맥 | 할 일 | 갈래 순서 |
|---|---|---|
| 처음 7일 | 환영하고 첫 스윙만 받으면 된다 | comeback → milestone → goal → cheer |
| 오늘 또 열었다 | 방해하지 않기 — 이미 습관이 든 사람이다 | goal → coach → cheer |
| 1~3일 만에 | 흐름을 끊지 않게 이어주기 | streak → rank → practice → with → … |
| 4~13일 만에 | 프로가 아직 보고 있다고 알리기 — 여기서 잡아야 한다 | coach → comeback → with → … |
| 14~29일 만에 | 부담을 0으로. 숫자로 혼내지 않기 | comeback → coach → with → cheer |
| 30일 넘어서 | 한 문장만. 숫자는 전부 뺀다 | comeback → cheer |

그다음 —
1. 「오늘만」 카드(`u:true`)가 있으면 문맥을 무시하고 그게 이긴다. 내일이면 못 하는 말이다.
2. 없으면 문맥 순서대로 훑되 **최근에 쓴 갈래는 건너뛴다.** 갈래가 한 바퀴 돌게 하는
   장치다 — 이게 없으면 앞 갈래에 카드가 많은 회원은 뒤쪽 갈래를 영영 못 본다.
   열심히 쓰는 사람이 제일 좁은 화면을 보게 된다.
3. 갈래 안에서는 최근 5장에 있는 카드를 건너뛴다.
4. 다 없으면 응원.

### 정해둔 것

- **확률로 뽑지 않는다.** 비율로 돌리면 상황에 안 맞는 카드가 반드시 나온다 —
  3주 잠수한 사람에게 「함께한 지 148일」이, 오늘 한마디를 받은 사람에게
  「천천히 가도 괜찮습니다」가 뜬다. **비율은 정하는 게 아니라 결과다.**
- **「성장」 갈래는 안 넣는다.** 「다운스윙이 안정됐습니다」 같은 말은 앱이 스윙을
  평가한다는 뜻이라, 스윙 스코어를 뺀 이유와 부딪친다. 대신 **프로가 쓴 말을 그대로 인용**한다.
- 못 세는 숫자(「15분 동안 작성」) · 이모지 · 「회원님」도 뺐다.

### 아직 안 붙였다

`src/runtime-v3.js` 에 들어가 있지 않다. 붙이려면 회원별로 필요한 것 —
마지막 방문일(gap), 최근에 보여준 카드·갈래(seen / seenG), 연속 일수, 이번 달 집계.
`seen`·`seenG` 는 기기에 두면 폰 바꿀 때 리셋되니 서버(`profiles`)에 두는 게 맞다.
