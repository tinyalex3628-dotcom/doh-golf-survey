개인정보 처리방침

시행일 2026년 8월 9일 · 버전 1.0 (베타)

넥스트 스윙(NEXT SWING, 이하 "서비스")은 골프 스윙 영상을 올리면 이도형 프로가 직접 보고 코칭을 남겨주는 서비스입니다. 운영자 이도형(이하 "운영자")은 개인정보 보호법을 비롯한 관련 법령을 지키며, 이 방침을 통해 어떤 정보를 왜 모으고 어떻게 지키는지 알립니다.

한눈에 보기 — 모으는 것은 계정 정보와 회원이 직접 올린 스윙 영상·연습 기록이 전부입니다. 광고 목적 수집이나 제3자 판매는 없습니다. 올린 영상은 본인과 이도형 프로만 볼 수 있고, 탈퇴하면 즉시 모두 삭제됩니다.

1. 수집하는 개인정보와 수집 방법

구분항목수집 시점
계정 아이디, 비밀번호, 닉네임, 이름(선택) 회원가입 시 직접 입력
콘텐츠 스윙 영상, 촬영 방향(정면·측면), 사용 클럽, 연습 메모 회원이 직접 올릴 때
이용 기록 가입일, 코칭 요청·열람 시각, 이용 플랜, 앱 안내 화면 표시 기록 서비스 이용 과정에서 자동 생성
접속 기록 IP 주소, 접속 일시 등 통신 기록 클라우드·호스팅 사업자의 시스템에서 자동 생성
  • 비밀번호는 복원할 수 없는 형태(해시)로만 저장되며, 운영자도 원문을 볼 수 없습니다.
  • 이름은 선택 항목이며, 베타 운영 기간에 프로가 회원을 알아보기 위해서만 쓰고 베타 종료 시 삭제합니다.
  • 이메일 주소·전화번호·주소·결제 정보는 수집하지 않습니다. (베타 기간에는 결제 기능이 없습니다.)

2. 수집한 정보를 쓰는 곳

  • 스윙 코칭 제공 — 올린 영상을 이도형 프로가 확인하고 코멘트·월간 요약을 남기는 일
  • 계정 관리 — 로그인, 기기 변경 시 기록 이어가기, 본인 확인
  • 서비스 운영 — 연습 기록 달력, 이용 현황 표시 등 앱 기능 제공

위 목적 밖의 용도(광고, 마케팅, 프로필 판매 등)로는 쓰지 않습니다. 목적이 바뀌면 미리 알리고 별도 동의를 받습니다.

3. 누가 볼 수 있는가

  • 올린 영상과 기록은 본인과 이도형 프로만 볼 수 있습니다. 서버 접근 규칙(행 단위 보안)으로 강제되며, 다른 회원에게는 보이지 않습니다.
  • 영상 저장소는 비공개이며, 재생할 때마다 1시간 뒤 만료되는 임시 링크로만 열립니다. 링크가 밖으로 새어도 1시간이 지나면 쓸 수 없습니다.

4. 제3자 제공 및 처리 위탁

개인정보를 제3자에게 제공하거나 판매하지 않습니다. 다만 서비스를 돌리기 위해 아래 업체에 처리를 위탁합니다.

수탁 업체맡기는 일
Supabase Inc.데이터베이스·영상 저장소·로그인 인증 (클라우드 인프라)
GitHub, Inc.웹 페이지 호스팅

수탁 업체는 위탁받은 일 외의 목적으로 개인정보를 처리할 수 없습니다. 위 업체의 서버는 해외에 있을 수 있으며, 이 경우 개인정보가 국외에서 보관·처리됩니다.

5. 보관 기간과 파기

  • 회원으로 있는 동안 보관합니다 — 지난 스윙과 코칭 기록을 다시 보는 것이 서비스의 핵심이기 때문입니다.
  • 탈퇴하면 즉시 전부 삭제합니다. 스윙 영상, 코멘트, 연습 기록, 닉네임, 계정이 서버와 저장소에서 지워지며 되돌릴 수 없습니다.
  • 탈퇴는 앱 안 마이 › 회원 탈퇴에서 직접 할 수 있습니다. 별도 문의나 승인 절차 없이 그 자리에서 끝납니다.
  • 법령이 보존을 요구하는 기록이 생기면(예: 결제 도입 후 거래 기록) 해당 법령이 정한 기간만 분리 보관 후 파기합니다.

6. 이 기기에 남는 것

올린 영상은 전송 실패에 대비해 회원의 기기(브라우저 저장소)에도 보관됩니다. 이 사본은 회원의 기기에만 있으며 운영자는 접근할 수 없습니다. 앱 안에서 영상을 지우거나 탈퇴하면 기기 사본도 함께 지워집니다. 쿠키는 로그인 상태 유지와 화면 설정 저장에만 쓰며, 광고·추적 목적의 쿠키는 없습니다.

7. 회원의 권리

  • 자기 정보를 언제든 열람·수정·삭제할 수 있습니다. 영상 삭제와 닉네임 변경, 회원 탈퇴는 앱 안에서 직접 할 수 있고, 그 밖의 요청은 아래 연락처로 주시면 지체 없이 처리합니다.
  • 만 14세 미만은 가입할 수 없습니다. 만 14세 미만의 가입이 확인되면 해당 계정과 정보를 바로 삭제합니다.

8. 안전성 확보 조치

  • 모든 통신은 암호화(HTTPS)됩니다.
  • 비밀번호는 해시로만 저장합니다.
  • 데이터베이스는 행 단위 접근 규칙으로 본인과 프로 외의 접근을 차단합니다.
  • 영상 저장소는 비공개이며 만료되는 서명 링크로만 접근할 수 있습니다.
