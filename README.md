## 지금 실제로 돌아가는 것 (베타)

아래 2번 이후 내용은 **아직 안 만든 설계**입니다. 지금 링크로 열어볼 수 있는 건
`docs/` 안의 단일 HTML 두 개뿐이고, 서버·DB·저장소는 아직 없습니다.

| 주소 | 파일 | 무엇 |
|---|---|---|
| `/` | `docs/index.html` | 회원 앱 프로토타입 55화면. 열면 베타 안내가 먼저 뜬다 |
| `/admin` | `docs/admin.html` | 프로용 관리자 CRM. 데이터는 전부 예시 |

- 두 파일 모두 **빌드 산출물**입니다. 고칠 땐 원본(`build_v3.py` · `build_admin.py`)을
  돌려서 다시 만들어 넣습니다. HTML 을 직접 손대면 다음 빌드에 지워집니다.
- `?dev=1` 을 붙이면 화면 점프 · 등급 전환 패널이 나옵니다. 안 붙이면 폰 화면만 보입니다.
- 배포는 **Vercel 정적 호스팅**. `vercel.json` 이 루트의 Next.js 를 건너뛰고
  `docs/` 만 그대로 올리게 합니다. 링크가 검색에 걸리지 않도록 `noindex` 를 걸어뒀습니다.

## 1. 전체 구조를 쉽게 설명하면 (개발자 아니어도 OK!)

이 서비스는 **우체국 시스템**이라고 생각하면 쉬워요.

```
[신청자]                [클라우드 창고]              [프로님]
영상/사진/글을  ──보냄──▶  Supabase 에 저장  ──확인──▶  관리자 화면에서
올리고 신청                (안전한 창고)               영상 보고 피드백 작성
                                                        │
[신청자]                                                ▼
카톡 링크 눌러서  ◀──알림──  카카오 알림톡  ◀──발송──  피드백 저장 완료
피드백 열람
```

- **Supabase(수파베이스)** = 무료로 시작할 수 있는 "클라우드 창고 + 회원 관리" 서비스예요.
  신청자가 올린 영상과 프로님이 올린 분석 영상이 전부 여기에 안전하게 저장됩니다.
- **"나에게 어떻게 전달되나?"** → 카톡이나 이메일로 파일을 받는 게 아니라,
  **프로님 전용 관리자 화면**(`/admin`)에 신청 목록이 쌓입니다. 거기서 바로 영상을 보고 피드백을 작성해요.
  파일을 주고받으며 잃어버릴 일이 없어서 이 방식이 제일 깔끔합니다.
- **"내 피드백은 어떻게 전달되나?"** → 피드백을 저장하면 **비밀 링크**(예: `내사이트/f/abc123...`)가 만들어져요.
  이 링크를 카카오 알림톡으로 자동 발송하거나(설정 후), 그 전까지는 **링크 복사 버튼**으로 복사해서 직접 카톡으로 보내면 됩니다.
  링크는 30일간만 열려요.

|---|---|---|

| `/f/토큰` | 피드백 열람 페이지 (카톡 링크로 진입, 로그인 불필요, 30일) | 신청자 |

## 3. 처음 한 번만 하는 준비 (약 30분)

### ① Supabase 만들기 (창고 준비)
1. https://supabase.com 가입 → "New project" 생성 (무료)
2. 왼쪽 메뉴 **SQL Editor** → 이 저장소의 `supabase/schema.sql` 파일 내용을 전부 붙여넣고 **Run**
   → 테이블(신청서, 파일, 피드백)과 보안 규칙, 저장소가 한 번에 만들어져요.
3. **Settings → API** 에서 `URL`, `anon key`, `service_role key` 3개를 복사해두세요.

### ② 카카오 로그인 연결
1. https://developers.kakao.com → 애플리케이션 추가
2. **카카오 로그인 활성화** 후 Redirect URI 에
   `https://내프로젝트.supabase.co/auth/v1/callback` 등록
3. Supabase 대시보드 → **Authentication → Providers → Kakao** 켜고
   카카오에서 받은 REST API 키 / Client Secret 입력

### ③ 배포 (인터넷에 올리기)
1. https://vercel.com 가입 → 이 GitHub 저장소 연결 → Deploy (무료)
2. Vercel 프로젝트 **Settings → Environment Variables** 에 `.env.example` 파일에 있는
   값들을 입력 (Supabase 3개 + 사이트 주소는 필수)

### ④ 프로님 계정을 관리자로 등록
1. 배포된 사이트에서 프로님 카카오 계정으로 한 번 로그인
2. `/admin` 접속 → "접근 권한이 없어요" 화면에 **내 계정 ID**가 표시됨
3. Supabase **SQL Editor** 에서 아래 한 줄 실행 (ID 부분만 바꿔서):
   ```sql
   insert into admins (user_id) values ('여기에-내-계정-ID');
   ```
4. 다시 `/admin` 들어가면 신청 목록이 보여요! 🎉

## 4. 카카오 알림톡 자동 발송 (나중에 해도 됨)

알림톡은 카카오 정책상 **사업자 등록 + 카카오 비즈니스 채널 + 템플릿 승인**이 필요해서
시간이 좀 걸려요. **그 전까지는 "피드백 링크 복사" 버튼으로 직접 카톡을 보내면 똑같이 동작합니다.**

준비가 되면:
1. https://solapi.com 가입 (알림톡 발송 대행사, 건당 몇 원 수준)
2. 카카오 비즈니스 채널 연동 + 알림톡 템플릿 등록/승인
   - 템플릿 변수: `#{접수번호}`, `#{진단}`, `#{링크}`, `#{기한}`
3. Vercel 환경변수에 `SOLAPI_...` 5개 입력 → 이후 "카카오 알림 보내기" 버튼이 자동 발송으로 바뀜

## 5. 매일 쓰는 방법 (프로님 루틴)

1. `/admin` 접속 → 새 신청 확인
2. 신청 클릭 → 회원 영상/고민 확인
3. 화면 녹화로 분석 영상 만들기 (기존에 하시던 방식 그대로)
4. 분석 영상/사진 업로드 + 한 줄 진단 + 상세 글 + 영상 구간 입력
5. **피드백 저장하기** → **카카오 알림 보내기** (또는 링크 복사해서 직접 카톡)

## 6. 개발자용 정보

- Next.js 14 (App Router) + Supabase (Auth/DB/Storage) + TypeScript
- 로컬 실행: `.env.example` → `.env.local` 복사 후 값 채우고 `npm install && npm run dev`
- 디자인: `design_handoff` 핸드오프 문서의 토스 스타일 B안 기준 (토큰은 `app/globals.css`)
