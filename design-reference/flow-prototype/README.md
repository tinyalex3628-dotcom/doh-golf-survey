# Handoff: DOH — 골프 스윙 코칭 앱 유저 플로우 프로토타입

## Overview
DOH는 아마추어 골퍼가 자신의 스윙을 촬영·분석하고, 프로의 스윙과 비교하며,
프로에게 문의하고 구독(관리 플랜)으로 전환하는 것을 목표로 하는 모바일 골프 코칭 앱입니다.
이 번들은 앱의 **전체 화면 이동 플로우(user flow) 동작 프로토타입**으로,
23개 화면과 화면 간 내비게이션, 상태 전환, 팝업/토스트/애니메이션을 담고 있습니다.

## About the Design Files
이 번들의 파일들은 **HTML로 만든 디자인 레퍼런스**입니다 — 의도한 외형과 동작을 보여주는
프로토타입이며, 그대로 프로덕션에 복사해 쓰는 코드가 아닙니다.
목표는 이 HTML 디자인을 **대상 코드베이스의 기존 환경(React, Vue, SwiftUI, Flutter, native 등)에서
그 환경의 확립된 패턴·라이브러리를 사용해 재현**하는 것입니다.
아직 코드베이스가 없다면, 프로젝트에 가장 적절한 프레임워크를 선택해 구현하면 됩니다.

**파일 열람 방법**
- `DOH Flow Prototype (standalone).html` — 의존성 없이 브라우저에서 바로 열리는 단일 파일. **동작 확인용으로 이것을 여세요.** (폰트가 인라인되어 용량이 큽니다.)
- `DOH Flow Prototype.dc.html` — 사람이 읽기 좋은 소스. 템플릿(마크업)과 로직 클래스(`class Component`)가 한 파일에 있습니다. **디자인/로직 파악은 이 파일을 읽으세요.**
- `support.js` — 위 소스 파일을 브라우저에서 실행하기 위한 런타임(재구현 대상 아님).

> `.dc.html`은 자체 경량 렌더링 런타임을 쓰는 포맷입니다. 템플릿의 `{{ ... }}` 홀은
> 로직 클래스 `renderVals()`가 반환하는 값으로 채워지고, `<sc-if>`/`<sc-for>`는
> 조건부·반복 렌더링입니다. React의 조건부 렌더링/`.map()`과 1:1로 대응됩니다.

## Fidelity
**High-fidelity (hifi).** 최종 색상·타이포그래피·간격·모서리·그림자·인터랙션이 확정된 목업입니다.
개발자는 대상 코드베이스의 라이브러리·패턴을 사용하되 아래 디자인 토큰과 화면 명세대로
**픽셀에 가깝게** 재현해야 합니다. (영상/AI 분석 결과·지도 등 실제 데이터가 필요한 부분은
"준비 중" 플레이스홀더로 표시되어 있습니다 — 실제 연동은 코드베이스 몫.)

디바이스 프레임(378×800 폰 목업)과 좌측 "User Flow 범례" 사이드바는 **프로토타입 설명용 껍데기**이며
실제 앱에는 포함되지 않습니다. 실제 앱 화면은 폰 프레임 안쪽(상단바 + 스크롤 본문 + 하단 탭바)입니다.

## App Shell (모든 화면 공통)
폰 스크린(378×800, 내부 뷰포트) 안은 3층 구조:
1. **상단바** (height 52px): 홈이면 좌측 `DOH` 워드마크, 그 외엔 좌측 뒤로가기(‹) 원형 버튼 + 가운데 화면 제목.
2. **스크롤 본문** (`flex:1; overflow-y:auto; padding:8px 16px 92px`): 화면별 콘텐츠. 진입 시 슬라이드 애니메이션(앞으로=우→좌 `scrIn`, 뒤로=좌→우 `scrBack`, 0.26s ease).
3. **하단 탭바** (fixed, blur 배경 `rgba(247,244,236,.94)`): **홈 / 스윙분석 / 골프사전 / 프로필** 4탭. 활성 탭은 아이콘이 사각(radius 7px) + Ink 색, 라벨 800.

전역 오버레이: **바텀시트**(팝업, `sheetUp` 0.28s + 배경 페이드 `fadeBg`), **토스트**(하단 96px, pill, 1.7s 후 자동 사라짐).

## Screens / Views
아래 각 화면은 `route` 값 하나에 대응하며, 상세 목적은 소스의 `this.PAGES` 객체에 한 줄씩 정리돼 있습니다.
탭(`tab`) 소속은 하단 탭바 활성 상태를 결정합니다.

### 1. `home` — 홈 (탭: home)
- **목적:** 앱 시작점. 인사 + 이번 주 숙제 카드 + 바로가기 4그리드.
- **레이아웃:** 인사 헤더 → 흰 "이번 주 목표 숙제" 카드(태그·"N개 남음" 칩·진행바 40%·마감일·CTA) → "바로가기" 2×2 그리드(스윙 분석[다크], 프로와 비교[골드 보더], 프로에게 문의, 구독 안내).
- **이동:** 숙제 카드→`homework`, 그리드→`hub1`/`hub2`/`feedback`/`subscription`.

### 2. `homework` — 이번 주 목표 숙제 (탭: home)
- **목적:** 프로가 낸 숙제 확인/수행. **4개 상태 탭 포함**(숙제 없음 / 이번 주 / 다 했어요 / 모르겠어요) — 각 상태별 다른 UI.
  - `empty`: 빈 상태(📭) + "스윙 전송하기" CTA.
  - `has`(기본): 숙제 카드 리스트(제목·마감·진행바·설명) + "숙제 다 했어요"/"잘 모르겠어요" CTA.
  - `done`: 완료 축하 다크 카드(🎉) + 업로드 CTA.
  - `confused`: 질문 유도(？) + 문의 CTA.
- **이동:** `upload`, `subscription`.

### 3. `hub1` — 스윙 분석 (탭: analysis)
- **목적:** 스윙 관리 시작점. 상단 "AI 스윙분석+설문" 강조 카드 → 하단 4개 페이지 그리드(업로드/갤러리/단독분석/멀티비교) → "프로와 비교하기(Hub2)" 진입 배너.

### 4. `aiSurvey` — AI 스윙분석 + 설문 (탭: analysis) **← 멀티 페이즈 마법사**
- 내부 `aiPhase` 상태로 흐름 제어: `intro`(3단계 안내) → `survey1`(8문항 설문) → `register`(정면·측면 업로드) → `survey2`(추가 3문항) → `result`(점수 게이지 72점 + 핵심 피드백/잘한 점 + 신체테스트 제안) → `physical`(신체 테스트 4항목).
- 설문 각 문항: 진행바 + 질문 + 옵션 리스트(단일 선택, 선택 시 다크 배경+골드 체크) + 이전/다음. 미선택 시 "다음" 비활성(회색).
- 종료 시 토스트 후 `hub1`으로 복귀.

### 5. `upload` — 스윙 업로드 (탭: analysis)
- 정면·측면 2개 슬롯(탭하면 업로드 상태 토글: 흰 카드→다크 카드+✓). 하나라도 업로드되면 "단독 분석으로 이동" CTA 활성.

### 6. `gallery` — 내 스윙 갤러리 (탭: analysis)
- 날짜 그룹(이번 주/6월)별 2열 그리드 썸네일(측/정면 라벨·클럽·태그). 탭→`single`.

### 7. `single` — 단독 분석 (탭: analysis)

- AI 피드백 카드 → "멀티스크린 비교"/"프로와 비교하기"/"프로에게 물어보기" 이동.

### 9. `hub2` — 프로와 비교하기 (탭: analysis) **← DOH 핵심 차별화**

### 10. `proSelect` — 프로 선택 (탭: analysis)

## Interactions & Behavior
- **내비게이션:** `go(route)`가 `history` 스택에 현재 화면을 push하고 이동(`dir:'fwd'`). 뒤로가기 `back()`은 스택 pop(`dir:'back'`). 방향에 따라 슬라이드 인 애니메이션이 달라짐.
- **화면 전환 애니메이션:** `scrIn`(translateX 22px→0, opacity 0→1) / `scrBack`(-22px→0), 둘 다 0.26s ease. `route`를 key로 사용해 리마운트.
- **바텀시트:** `sameOpen` true 시 표시. 배경 탭 또는 "이해했어요"로 닫힘. `sheetUp` 0.28s cubic-bezier(.2,.8,.2,1), 배경 `fadeBg` 0.2s.
- **토스트:** `toastMsg(t)`가 1.7초 타이머로 자동 소멸(캡처·저장 등 피드백).
- **프레임 슬라이더 ↔ P버튼 연동:** 슬라이더 값(0–100)과 `pIdx`(0–9)가 양방향 동기화. `setFrameFromP(i)` → `frame = round(i/9*100)`; `onFrame` → `pIdx = round(v/100*9)`.
- **선 그리기 토글:** `line` true면 SVG 각도선이 기울고(각도 32°) 배지 텍스트 변경.
- **CTA 활성 조건(게이팅):** 업로드/프로/카메라 선택 전에는 "다음" 버튼이 회색 비활성(`rgba(27,38,32,.08)` 배경, `.35` 텍스트), 조건 충족 시 Ink 활성.
- **눌림 상태:** 거의 모든 버튼에 `style-active`로 `transform:scale(.97~.99)` 또는 `opacity` 변화.

## State Management
소스 `constructor`의 `this.state`가 전부입니다:
- `route`(현재 화면), `history[]`(뒤로가기 스택), `dir`('fwd'|'back' — 애니메이션 방향).
- `up[2]`(업로드 정면/측면 완료 bool), `pro`('m'|'f'|null), `cam`('정면'|'측면'|null).
- `pIdx`(0–9 현재 P포지션), `frame`(0–100 슬라이더).
- `line`(각도선 표시), `sameOpen`(바텀시트), `toast`(문자열).
- `hwState`('empty'|'has'|'done'|'confused' — 숙제 화면 상태).
- `aiPhase`('intro'|'survey1'|'register'|'survey2'|'result'|'physical'), `aiI`(현재 문항 인덱스), `aiA1`/`aiA2`(설문 답 맵).
- `dictQ`(사전 검색어).

데이터 페칭 요구: 현재는 전부 하드코딩(더미). 실제 구현 시 스윙 영상/AI 분석 결과/프로 영상/사전 데이터/구독 상태는 백엔드 연동 필요.

## Assets
- **폰트:** Pretendard (jsDelivr CDN). standalone 파일엔 인라인되어 있음.
- **아이콘/그래픽:** 모두 **이모지 텍스트**(🎬 ⚔ 💬 📖 📹 🖼 ⚖ 📝 🎁 📍 👤 등)와 CSS 도형/그라디언트로 표현. 별도 이미지 에셋 없음. 실제 앱에서는 코드베이스의 아이콘 세트로 대체 권장.
- **영상/썸네일:** CSS 그라디언트 + 실루엣 도형 플레이스홀더. 실제 영상 없음.
