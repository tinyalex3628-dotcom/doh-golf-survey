# HF Spaces 배포 — 컴맹용 따라하기 (10분, 1번만)

> 이거 한 번만 해두면 **주소가 영구 고정**돼서, 다시는 콜랩 켜고 주소 복사 안 해도 돼요.
> analyzer2에 주소 한 번만 넣으면 그다음부턴 **영상 올리고 [서버로 분석]** 만 누르면 끝.

## 0. 준비
- huggingface.co 가입 (무료). 사지방에서 열림.

## 1. Space 만들기
1. https://huggingface.co/new-space 접속
2. **Space name**: 아무거나 (예: `doh-golf`)
3. **License**: 아무거나 (예: mit)
4. **SDK**: **Gradio** 선택
5. **Hardware**: **CPU Basic** 선택 (무료)
   - ⚠️ **ZeroGPU는 PRO($9/월) 전용**이라 무료로는 못 씀. 그래서 무료는 CPU Basic.
   - CPU는 느려요(스윙당 **1~3분**). app.py가 ~90프레임으로 줄여 처리해 감당되게 해뒀음.
   - "빠른 게 낫다" 싶으면: **콜랩(무료 GPU)** 을 계속 쓰거나(주소 복붙 감수), PRO 결제.
6. **Visibility**: Public (무료). **Create Space**

## 2. 파일 3개 올리기
Space 화면에서 **Files ▸ Add file ▸ Upload files** 로 이 폴더(`hf_space/`)의 3개를 올려요:
- `app.py`
- `requirements.txt`
- `README.md`

(또는 **Files ▸ Add file ▸ Create a new file** 로 하나씩 복붙해도 됨.)

## 3. 빌드 기다리기
- 올리면 자동으로 빌드 시작. 오른쪽 위 상태가 **Building → Running** 되면 됨.
- 처음엔 NLF 모델(470MB) 받느라 몇 분 걸려요. **Running** 뜨면 준비 완료.

## 4. 주소 확인
- Space 화면 오른쪽 위 **⋮ ▸ Embed this Space** 또는 그냥 브라우저 주소창의
  `https://<내아이디>-doh-golf.hf.space` 가 백엔드 주소예요. (끝에 `/` 없이 복사)

## 5. analyzer2에 딱 한 번 넣기
1. analyzer2 v24 열기 (`Ctrl+Shift+R`)
2. `☁️ GPU 서버로 3D 정밀분석` 칸에 **위 hf.space 주소** 붙여넣기
3. 영상 올리고 **[서버로 분석]**
→ 끝. 이제부턴 주소 그대로 저장돼서 **영상만 바꿔 올리면 원클릭**.

---

## 문제 생기면
- **CPU라 너무 느리거나 뻗음** → Space 설정 ▸ Settings ▸ Hardware ▸ **ZeroGPU**로 변경.
  (ZeroGPU가 목록에 없고 PRO 요구하면, 알려줘요 — CPU 최적화나 다른 무료 GPU 방법 찾아줄게요.)
- **analyzer2에서 "Failed to fetch"** → Space가 **Running** 상태인지 먼저 확인. (Sleeping이면 Space 한 번 열어서 깨우기.)
- **CORS 에러** → 알려줘요. app.py에 CORS 허용 한 줄 추가하면 됨.

## 나중에 (사용자 많아지면)
- ZeroGPU 무료 할당량 넘으면 → HF PRO($9) 또는 상시 GPU 서버로.
- **그때도 analyzer2는 URL만 바꾸면 됨** (계약 doh.vision.v1 동일).
